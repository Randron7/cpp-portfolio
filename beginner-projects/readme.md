\# 📋 Task Manager (C++)



A simple console task manager written in C++.



This project was created to practice:



\* C++ basics

\* functions

\* arrays

\* working with strings

\* console input/output



---



\# 🚀 Features



\* Add a task

\* Show all tasks

\* Exit the program



---



\# 🖥 Example Menu



```

=== Task Manager ===

1\. Add a task

2\. Show tasks

3\. Log out

```



---



\# 🛠 Technologies



\* C++

\* iostream

\* string

\# 📦 How to Run



1\. Download the repository

2\. Compile the program



```

g++ main.cpp -o task\_manager

```



3\. Run the program



```

./task\_manager

```
